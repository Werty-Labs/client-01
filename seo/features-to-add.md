# SEO Features to Add

This document tracks deferred SEO features and content gaps that need to be addressed to fully align with the SEO plan.

## Feature 1: Destinations Page — Sri Lanka Travel Map
- **Purpose:** Capture the `tour map of sri lanka` keyword cluster (590 UK monthly searches, KD: 5 — one of the lowest-competition, highest-ROI opportunities in the CSV data).
- **What to build:** An interactive or visual travel route map embedded on the `/destinations` page, showing the key locations (Colombo → Sigiriya → Kandy → Ella → Yala → Mirissa). Can be implemented as: (a) a static illustrated SVG/PNG image map, or (b) an embedded Google Maps iframe with custom pins.
- **SEO impact:** Captures the entire `tour map`, `travel map sri lanka`, and `sri lanka travel guide map` keyword cluster without additional article content.
- **Target H2 anchor text on page:** `"Sri Lanka Travel Map & Route Planner"`

## Feature 2: Tours Page — Sri Lanka & Maldives Category
- **Purpose:** Capture `sri lanka and maldives tour package` (480 UK vol, KD: 5, CPC: £1.55) — the highest-priority commercial keyword in the CSV data that maps directly to a real Tarragon product.
- **What to build:** A dedicated section or filter label on the `/tours` page for "Sri Lanka & Maldives" combination packages. Long term, a dedicated sub-page `/tours/sri-lanka-maldives` would be ideal.
- **SEO impact:** A new site can rank for this KD: 5 term within 2–4 months. It is the single fastest commercial keyword win available.
- **Target anchor text:** `"Sri Lanka & Maldives Combination Holidays"`
